# 优惠券 A/B 实验效果评估

## 一、研究问题

优惠券是否能够提高用户转化率、客单价，并降低退款率？

## 二、实验设计

将用户随机分为处理组和对照组：

- 处理组：发放优惠券
- 对照组：不发放优惠券

通过比较两组用户的结果，评估优惠券的实际效果。

## 三、主要指标

- 转化率
- 客单价
- 退款率

## 四、数据字段

- `user_id`：用户编号
- `group`：实验分组
- `coupon`：是否发放优惠券
- `converted`：是否转化
- `order_amount`：订单金额
- `refund`：是否退款
- `date`：日期

## 五、计划使用的方法

- 描述性统计
- 两组均值和比例比较
- 假设检验
- 置信区间
- 回归调整
- 异质性分析
