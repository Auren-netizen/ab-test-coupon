### 三、今天踩过的坑（重要经验）

1. **文件没保存 = Git 看不见**
   - 在 VS Code 里编辑 README 后 Changes 列表是空的
   - 原因：VS Code 标签页上有白点 = 未保存，Git 只认磁盘上的文件
   - 教训：写完代码先 Ctrl+S

2. **`python` 命令用的是系统 Python，不是 Anaconda 环境**
   - 直接敲 `python` 运行报 `No module named 'pandas'`
   - 原因：系统默认 Python（3.14.7）和 Anaconda 环境（3.13.16）是两套东西
   - 解决：用完整路径 `D:\Softwares\Anaconda\installation\envs\day\python.exe`，
     或做了一键启动脚本 `day环境终端.bat`（自动激活环境 + 进入项目目录）

3. **相对路径是相对"当前所在目录"的**
   - 在 `D:\github\cangku` 执行 `python src\generate_data.py` 报"找不到文件"
   - 原因：文件在 `cangku\ab-test-coupon\src\` 下，必须先 `cd` 进项目目录

4. **PyCharm 解释器路径失效导致安装按钮变灰**
   - 项目配置指向了已改名的旧文件夹，"可用软件包"无法安装
   - 解决：重新选择解释器指向 `envs\day`

5. **Codex 图片上传失败的排查思路**
   - 本地会话：图片以临时文件形式传给模型（路径引用），通道正常
   - ChatGPT Work 云端会话：上传走云端存储，曾出现"文件记录生成了但内容没传到"的已知 bug，后自行恢复
   - 经验：要给 AI 看的素材，保存成文件让它读路径最稳
